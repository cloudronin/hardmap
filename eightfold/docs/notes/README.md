# Banked idea notes

**Epistemic status is structural here, not a header line.** Files in this directory are *banked ideas*:
dated, origin-attributed, and **carrying no scored claim**. Nothing in `notes/` is a finding.

`findings/` holds scored results. `specs/` holds work that was commissioned. This directory holds
directions that were thought through, written down, and deliberately not executed — so that a later
decision to build inherits the reasoning instead of re-deriving it.

**A note may be cited by the writeup only as a dated position or a banked direction, never as evidence.**
Where a note names a condition, a citation, or a fill route, that route is *proposed*, not pinned: the
Bridge Ledger is the authority on what is pinned, and a note asserting otherwise about itself does not
change that. See `docs/paper/claims-map.md`, audit rule 7.
